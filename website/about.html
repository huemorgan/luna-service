AI that compounds your work.

Persistent, trustworthy, yours.

We built Luna because we needed an AI agent that actually followed through. One that remembered what we told it, asked before it acted, learned from its mistakes, and could be taken with us if we left. Nothing like that existed. So we built it. And we made it open source — because the best tools should belong to the people who use them.

The Principles

🔓

Open by default

The agent platform is MIT licensed. Every capability, open. If we break this promise, you have a fork.

🛡️

Trust by architecture

Approvals are hard gates, not prompts. Isolation is physical, not logical. Privacy is cryptographic, not policy.

📈

Compounding value

Memory persists. Behavior improves. Plugins extend. Every interaction makes the next one better.

🤝

Yours to keep

Self-host for free. Export everything. Your agent, your data — open by design, not by concession.

Luna is built by Novalystrix. We're a small team that believes AI agents should work for people, not platforms.
