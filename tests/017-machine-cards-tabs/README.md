# 017 — Machines page: cards + tabs

Browser-driven scenarios for the new per-machine card layout.

1. `01-card-layout.md` — each machine renders as an expandable card; header
   shows the right summary; chevron toggles.
2. `02-tabs.md` — Overview / Settings / Webhooks tabs render and switch.
3. `03-settings-connectors.md` — the Connectors plugin section explains the
   three options; selecting each one writes via PATCH; "Inherit" clears the
   override; the row badge reflects the override.
4. `04-webhooks-tab.md` — only this agent's links + deliveries show under its
   card; "Add link" pre-fills the agent slug; new link appears in the card and
   on the global Relay page.
