# 08 — Back to Dashboard

## Setup
- On `/dashboard/agents/{id}`

## Steps
1. Click the breadcrumb "Dashboard" link (or back button if that's the design)
2. Verify navigation

## Expected
- URL becomes `/dashboard`
- Agent list shown
- Same session, no re-login

## Pass criteria
- One click returns to dashboard

## Fail criteria
- Browser back button is the only way back (no UI affordance)
