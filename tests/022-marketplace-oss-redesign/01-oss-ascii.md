# 01 — Open Source page: ASCII / terminal look

**Goal:** `/products/open-source` reads as a terminal/ASCII page and keeps all the
021 substance.

## Steps
1. Load `/products/open-source`.
2. Observe the hero: monospace type, a **terminal window** with typed lines
   (`$ luna plugin init`, `$ luna up`, `# your agent. your machine. MIT.`) and a
   blinking block caret.
3. Scroll. Confirm these sections are present and legible in the mono/green idiom:
   - "Why open" — trust-because-open (vault / rollback / approval gates).
   - "Lean core, expand anywhere" — the six points + an **ASCII architecture
     diagram** (a `[core]` box with `[plugins]` hanging off it).
   - "Open-platform promise" — rendered like a `PROMISE.txt` terminal panel.
4. Confirm CTAs: `[ Star on GitHub ↗ ]` and `[ Read the docs ↗ ]` work, plus the
   soft "want it hosted? → Start free" cross-sell.

## Pass
- Page is clearly ASCII/terminal (monospace, near-black, green accent, square
  panels), not the violet glass look.
- All four content blocks above are present and readable.
- Screenshot saved to `screenshots/`.
