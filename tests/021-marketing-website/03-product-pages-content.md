# 03 — Product page content is present & truthful

**Goal:** The three product pages make the key claims, and don't overclaim.

## Pass criteria
- `/products/hosting`: ~60s signup, one bill / no BYOK / any model, physical isolation, "we never see your data", always-on triggers (paid), fleet dashboard, hosted-vs-self-host comparison. Primary CTA = Start free.
- `/products/open-source`: MIT, self-host on a $5 VPS, "open platform" promise, trustworthy *because* open, architecture brief (plugins/vault/rollback). CTAs: GitHub + Read docs + soft "try hosted".
- `/products/marketplace`: explains what a marketplace means for Luna (everything is a plugin), OSS plugins vs commercial packs, browse→one-click add. Genuinely-future items labelled **Coming soon** (no fake catalog). CTAs: Start free + Build a plugin.
