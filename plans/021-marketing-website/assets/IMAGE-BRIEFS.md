# Luna marketing imagery — briefs

Rule: every image must make a viewer **instantly get the concept**. Real photography
only (no 3D/space). The trick: a real person reacting to a **legible on-screen story
element** (checkmarks, rising chart, app-store grid, padlock/vault, contribution
graph). Coherent UI on screens is encouraged; no paragraphs of gibberish text, no logos.

Cohesion: 35mm editorial photo, natural soft light, shallow depth of field, modern
workplace, subtle cool cinematic grade (teal/indigo). Must look like a real photograph.

Loop: generate → look → does the story read 100%? → if not, make the on-screen signifier
more explicit and retry.

| File | Story (one line) | Must-read signifier | Avoid |
|------|------------------|---------------------|-------|
| `hero.png` | Reliable agents do your real work while you stay in control | Screen shows an AI working a to-do list, tasks ticked green | Stress, empty/ambiguous screen |
| `open-source.png` | Built in the open by a community; inspect everything | Big screen shows code editor + green contribution graph; several contributors | Single closed laptop, corporate feel |
| `hosting-service.png` | Sign up → your own private Luna ready in ~60s, managed | Screen shows onboarding with completed progress bar + "ready" check | Complex infra, config, stress |
| `marketplaces.png` | Browse plugins/connectors and add capability in one click | Screen shows app-store grid of installable tiles + add/install action | Generic desktop, ambiguous icons |
| `reliability.png` | It just runs, dependably, every time | Ops dashboard all green: checkmarks, steady uptime, no alerts; calm operator | Red alerts, stress, blank monitors |
| `trust-vault.png` | Hand it credentials & production with confidence; secrets sealed | Screen shows a credential vault: closed padlock, shield, masked secrets (dots) | Generic server room, hacker clichés |
| `self-improving.png` | The agent learns and keeps getting better over time | Screen shows a line chart clearly rising over time + upward trend | Flat/down charts, ambiguous data |
